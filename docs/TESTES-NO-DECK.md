# Testes no Deck: o que só você consegue conferir

Tudo o que dava para testar sem as mãos no Deck eu já testei: os 875 testes automáticos rodam no PC e no Deck, e a
revisão ao vivo do Deck (14 itens) passou. Esta lista é o que **precisa de você jogando**: sentir a vibração, apertar
botões, ver o jogo na tela, usar a TV, o PC e o Deck do seu irmão.

São **6 sessões curtas**, uma por dia (ou duas por dia, se quiser). Não precisa seguir a ordem à risca, mas a sessão 1
vem primeiro porque usa os jogos que já estão no Deck e cobre os itens mais novos.

**Como marcar:** ✅ deu certo · ❌ deu errado · ⏭️ pulei.

**Se algo der errado:** tire uma foto da tela (botão Steam + R1) e me mande dizendo **o número do teste**
(ex.: "teste 1.4 falhou"). Se puder, mande também `/diagnostico` no Telegram e cole a resposta.

---

## Sessão 1: jogos retrô e saída rápida (≈ 40 min, pode ser na bateria)
Antes: painel **… → Deck Commander → Retrô** deve mostrar "Ligado". Se não, toque em **Ligar**.

| # | Como fazer | O que deve acontecer | Resultado |
|---|---|---|---|
| 1.1 | Abra o **Nova the Squirrel** (NES). Jogue 1 min e aperte **L4** (botão de trás, esquerda em cima). | Aparece um aviso de "estado salvo" no canto. | |
| 1.2 | Ande um pouco e aperte **R4**. | O jogo volta para onde você estava no 1.1. | |
| 1.3 | Segure **L5** (esquerda embaixo) por 2–3 s. | O jogo anda para trás enquanto segura. | |
| 1.4 | Aperte **R5** uma vez, depois de novo. | 1º aperto: jogo acelerado (turbo). 2º: volta ao normal. | |
| 1.5 | O jogo está na velocidade normal? (música e movimento sem câmera lenta) | Velocidade normal. Antes da correção de 14/11 ele rodava na metade. | |
| 1.6 | Painel **… → Deck Commander → Retrô → Voltar 10 s**. | O jogo volta ~10 s. | |
| 1.7 | Painel **Qualidade → Botões → "A do Deck = A do jogo"**. Feche e abra o Nova. Aperte **A** e depois **B** do Deck. | O botão A do Deck faz o que o A do NES faz (pulo). Depois volte para "como o controle original", se preferir. | |
| 1.8 | **Saída rápida (RetroArch):** jogue até um ponto fácil de lembrar. Aperte o **botão Steam** → **Sair do jogo**. Abra o Nova de novo. | O jogo começa **no ponto onde você saiu**, sem menu. | |
| 1.9 | **Saída rápida (PS1):** mesmo do 1.8 no **Castlevania (PT-BR)**. | Começa no ponto. | |
| 1.10 | **Saída rápida (PS2):** mesmo do 1.8 em um jogo de PS2 (ex.: **God of War 1**). | Começa no ponto. | |
| 1.11 | **Saída rápida (PSP):** mesmo do 1.8 no **God of War Chains of Olympus (PT-BR)**. Depois teste se **todos os botões** funcionam (pular, atacar, menu). | Começa no ponto e todos os botões respondem (o defeito "PSP sem controle" foi corrigido em 14/11). | |
| 1.12 | Num jogo de PS1 ou PS2, pressione **L4** algumas vezes, saia pelo botão Steam e abra de novo. Aperte **R4**. | O R4 carrega o **seu** save do L4 (o "continuar" não mexe nos seus saves). | |

## Sessão 2: descanso e "continuar" de um dia para o outro (≈ 10 min + uma noite)
| # | Como fazer | O que deve acontecer | Resultado |
|---|---|---|---|
| 2.1 | Com um jogo aberto (qualquer um), aperte **rápido** o botão de ligar. Espere 10 s e aperte de novo. | O Deck dorme e volta **no mesmo quadro** do jogo. | |
| 2.2 | Jogue o **Castlevania (PT-BR)** até um lugar fácil de lembrar. Aperte o botão de ligar e deixe o Deck dormindo **até o dia seguinte** (fora da tomada). | No dia seguinte: ao acordar, o jogo está no mesmo quadro. | |
| 2.3 | Se a bateria tiver acabado no 2.2 (ou se você quiser forçar: segure o botão de ligar 3 s → **Desligar**), ligue o Deck e abra o Castlevania. | O jogo começa **no ponto salvo antes de dormir**, sem passar pelo menu. | |
| 2.4 | Num jogo de **Switch** (ex.: Luigi's Mansion 3), faça o 2.1. | Volta no mesmo quadro. (Switch não tem o "ponto de continuar"; vale só o descanso.) | |

## Sessão 3: modo repouso (≈ 5 min + o tempo do download)
Precisa: Deck **na tomada** e um download grande (o ideal são ~10 GB, como no seu pedido).

| # | Como fazer | O que deve acontecer | Resultado |
|---|---|---|---|
| 3.1 | Comece o download (magnet pelo Telegram). Confira no painel que ele está andando. | Download andando. | |
| 3.2 | Aperte **rápido** o botão de ligar. | A **tela apaga**, mas o Deck **não dorme** (a luz de carregar continua, o download segue). | |
| 3.3 | Pelo Telegram, mande `/status` com a tela apagada. | O bot responde e mostra o download avançando. | |
| 3.4 | Aperte o botão de ligar de novo. | A tela acende. Aperte mais uma vez para apagar. | |
| 3.5 | Espere o download terminar (pode ser durante a noite). | Ao terminar, o Deck **dorme sozinho**. Ao acordar, o jogo está na biblioteca, com capa. | |
| 3.6 | Faça o 3.2 **fora da tomada**. | O Deck dorme normal (na bateria o repouso não segura). | |

## Sessão 4: traduções, dublagem, detonado e vibração (≈ 40 min)
| # | Como fazer | O que deve acontecer | Resultado |
|---|---|---|---|
| 4.1 | **Castlevania (PT-BR):** jogue até a primeira conversa (o começo com o Richter já tem). | Falas em português, com acentos (é, ã, ç) aparecendo certos. | |
| 4.2 | Ainda no Castlevania: menu de equipamentos e a tela de escolher arquivo. | Menus em português; a tela de arquivos com os botões traduzidos. | |
| 4.3 | **God of War Chains of Olympus (PT-BR):** jogue uns 15 min além da abertura. | Textos e legendas em português. Imagens com texto e vídeos podem ficar em outra língua (não fazem parte da tradução). | |
| 4.4 | **Zelda Tears of the Kingdom:** abra e chegue em uma cena com falas. | Jogo em português e a fala **dublada** em PT-BR. | |
| 4.5 | Com o **God of War** aberto: painel **… → Deck Commander → Detonado**. | O jogo já vem escolhido; capítulos com títulos em português; o texto em português. | |
| 4.6 | Tire uma foto de uma frase traduzida estranha (qualquer jogo) e mande `/corrigir <jogo>` com a foto. | O bot confirma a correção. | |
| 4.7 | **Vibração no Switch:** jogue o **Luigi's Mansion 3** (aspirar fantasmas, levar dano). | O controle **vibra**. | |
| 4.8 | Painel **Qualidade → Perfil → Beleza**. Feche e abra um jogo de PS2. Depois **Desempenho**. | Beleza: imagem visivelmente mais nítida. Desempenho: mais liso. Volte para **Automático** no fim. | |

## Sessão 5: TV e PC (≈ 40 min, com a dock ou o cabo HDMI)
| # | Como fazer | O que deve acontecer | Resultado |
|---|---|---|---|
| 5.1 | Ligue o Deck na **TV/monitor** e abra um jogo de PS2. | Imagem nítida na TV (resolução sobe sozinha). Ao fechar o jogo, volta ao modo portátil. | |
| 5.2 | Na TV, com controle Bluetooth (Xbox/PS), jogue um pouco. | O controle funciona no jogo. | |
| 5.3 | Aba **Computador** → abra um jogo do PC (ex.: Clair Obscur). Espere 30–90 s. | O PC acorda, o jogo abre no PC e aparece no Deck. | |
| 5.4 | Jogue 5 min e saia: **botão Steam → Sair do jogo**. | Volta para o Deck; o PC volta a dormir sozinho depois. | |
| 5.5 | `/transferir <um jogo pequeno>` → **Enviar pro PC**. Depois `/saves <jogo>`. | O jogo chega no PC e os saves ficam iguais nos dois lados. | |

## Sessão 6: no sábado, com o Deck do seu irmão (≈ 1 h)
| # | Como fazer | O que deve acontecer | Resultado |
|---|---|---|---|
| 6.1 | Instale no Deck dele seguindo o Roteiro do [Manual, seção 15](MANUAL.md). | Painel aparece no menu **…**; o bot dele responde. | |
| 6.2 | `/familia par` num Deck e `/familia autorizar` no outro. | Os dois se enxergam. | |
| 6.3 | `/familia` e depois `/familia puxar <jogo traduzido>`. | O magnet entra na fila dele, e a tradução pronta vai junto. | |

## Só se der (não depende de você agora)
- **Continuar no GameCube/Wii:** não há nenhum jogo de GameCube/Wii no Deck. Quando tiver um, faça o 1.8 com ele.
- **Desinstalação completa:** **não rode no seu Deck** (ela desmonta tudo). Só se um dia quiser remover de verdade.
- **Deck OLED (tela de 90 Hz):** precisa de um OLED.
