# Perfis Steam Deck

Dados derivados de dragoonDorise/EmuDeck, revisão `d181675eb9ab43b270daf8b459d178b829258c5c`, sob GPLv3. A licença está em `COPYING`. O Azahar recebe apenas a seção Controls. O RPCS3 recebe apenas Player 1 Input. O XML do Cemu contém o perfil do GamePad.

Origens nessa revisão:

- `configs/azahar/qt-config.ini`
- `configs/info.cemu.Cemu/data/cemu/controllerProfiles/controller0.xml`
- `configs/rpcs3/input_configs/global/Default.yml`

O launcher identifica o modelo Valve e o Flatpak selecionado. Os arquivos são publicados por criação exclusiva. A biblioteca de jogos, BIOS, firmware, caminhos de NAND e saves ficam sob controle do emulador.
